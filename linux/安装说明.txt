SachiCat 黑猫键盘桌宠 · Linux 安装说明（统信 UOS / 银河麒麟 / 深度 / Ubuntu / Debian）

一、推荐：免密码安装（不需要开机密码 / 管理员权限）
  1. 解压这个压缩包。
  2. 在解压出来的文件夹空白处右键 →「在终端中打开」。
  3. 输入：bash install.sh   回车。
  安装后小猫会自动出现，以后在「启动器 / 开始菜单」搜索 SachiCat 即可打开。
  卸载：在同一个文件夹里运行 bash uninstall.sh

二、.deb 安装包
  双击 .deb 安装时，统信 / 麒麟会要求输入开机密码，这是系统安装软件的统一要求；
  不想输密码就用上面的免密码安装。点击「检查更新」会在默认浏览器打开虎鲸猫的 GitHub 发布页。

三、常见问题
  · 麒麟提示「安装失败 / 签名校验失败 / 未知来源」：
    打开「安全中心」→「应用保护」（或「应用执行控制」），把「检查应用程序来源 / 执行控制」
    改为「关闭」或「警告」后再安装；或者直接使用上面的免密码安装。
  · 统信 UOS 提示「无法安装未签名的软件」：
    「控制中心」→「通用」→「开发者模式」开启后再安装；或使用免密码安装。
  · 提示架构不匹配：x86_64 / 兆芯 / 海光电脑请下载 x86_64(amd64) 包，
    飞腾 / 鲲鹏 等 ARM 电脑请下载 arm64 包；龙芯（loongarch64 / mips64el）暂不支持。
  · 电脑变卡：右键小猫，确认「高帧率 60fps」没有勾选（默认就是关闭的省电模式）。
  · 小猫不跟着键盘动：Wayland 桌面请在登录界面切换到 X11 会话；或把当前用户加入 input 组：
    sudo usermod -aG input $USER  （重新登录后生效）
